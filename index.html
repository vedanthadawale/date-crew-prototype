Structure a rejection reason

Paste the matchmaker's free-text note on why a client passed on a profile. Try one of the samples or write your own.

In production this call would go to the Claude API for far more accurate, nuanced classification of real feedback (sarcasm, mixed reasons, local phrasing). This prototype uses transparent keyword rules so it runs with no API key and mocked data.
